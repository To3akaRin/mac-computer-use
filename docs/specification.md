# v0.1.0 实施规格

## 验收目标

交付独立的 macOS 自动化技能：Swift 原生工具、Node.js CDP 工具、中文命令文档和可复现实验。Agent 可自动发现技能，运行不依赖专属插件。

## 不变量

- 原生只读操作不改变前台；写入先复核目标，不切换桌面。
- 坐标单位明确，引用绑定窗口和快照；歧义和过期引用拒绝执行。
- 所有写操作可预演，预演不产生事件、DOM 写入、启动或重启。
- 用户空闲 2 秒才能借用前台，最多等待 15 秒；互斥锁串行化本用户的前台操作。
- 未知结果不重试。CDP 批量步骤在失败、拒绝或未知时停止。
- JSON 输出同时说明执行状态与验证范围，截图变化不能证明业务完成。
- CDP 默认限本机，连接和每条命令均有时间上限。

## 交付边界

目标 macOS 14+、Swift 6、Node.js 22.4+。当前 Apple Silicon 实机验证，其他架构和系统版本只列实际测试证据。无服务端、无数据库、无 Docker、无自动更新、无常驻守护进程。

## 实施顺序

原生内核与 CDP 各自先定义失败测试，再完成实现。整合后执行构建、自动化测试、专用测试窗口与 CDP 页面验收；同步帮助、文档、版本记录和验收报告。发布前检查独立仓库暂存范围、个人信息、凭据及名称约束，发布后核对远程提交与版本资源。
