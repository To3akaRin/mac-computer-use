# v0.2.0 通用安装与启动规格

## 已确认范围

同一份技能目录面向多 runtime 分发；提供标准元数据、统一启动、指定目录安装和 ZIP。维持 macOS 控制范围及原有命令兼容，不自动修改用户各客户端技能目录。

## 接口与验收标准

- `sh scripts/run.sh native ...` 在技能根目录增量构建，随后在调用者原工作目录执行，保留参数、JSON 与退出码。
- `sh scripts/run.sh cdp ...` 检查 Node.js 22.4+ 并执行 CDP，不要求 Swift。
- 安装器使用 `--skills-dir` 明确父目录，新增 `mac-computer-use/`。`--dry-run` 不创建任何文件，已有目标拒绝覆盖。
- 安装与 ZIP 共用逐文件清单，包含运行与文档资源，禁止隐式递归复制本机文件。
- 技能包仅含同名顶层目录，附独立 SHA-256；解压后与安装副本的清单内容一致。
- 标准入口与兼容表只描述已核实的格式和目录，不把协议支持当成九种客户端均已实测。

## 验证安排

启动测试使用隔离的模拟工具检查平台、版本、参数转发、符号链接和工作目录，不修改 HOME。安装测试使用临时父目录检查预演、拒绝覆盖、清单和 ZIP 完整性。整合后使用真实 Swift、Node.js 和测试窗口验证安装副本可执行，再通过官方参考校验器与 Skills CLI 发现检查。

安装和打包的原子提交使用 Python 3 标准库，目录提交采用 macOS 排他重命名，文件提交使用精确目标硬链接；外部进程竞争创建目标时拒绝，不进入已有目录。Skills CLI、ZIP 导入及日常运行无需此额外依赖。

本版不新增运行时环境变量。安装、打包、启动所用路径通过参数或脚本位置确定。
