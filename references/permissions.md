# 权限与故障

首先运行原生工具 `doctor`。命令只检查权限，不弹授权框、不修改系统数据库。

- 截图需要屏幕录制权限；AX 与输入需要辅助功能权限。授予权限的对象通常是承载命令的终端或 Agent 应用，取决于系统的责任进程判定。
- 在系统设置的“隐私与安全”中完成授权后，重新启动宿主并复查。不要盲目重复命令或写入 TCC 数据库。
- 锁屏、最小化、窗口未渲染或应用保护内容都可能让读取失败。失败必须如实返回，不能拿另一个窗口的图片冒充。
- 前台写入不自动跨桌面。当前桌面目标被覆盖时，受控激活后仍必须检查落点。
- 用户正在输入或另一个进程占用互斥锁时停止或有限等待。不要通过删除活跃锁文件绕过检查。
- CDP 必须由目标应用支持；发现监听端口后调用 `targets` 验证。拒绝非本机的调试地址与发现结果。
- `--relaunch` 是显式重启请求，可能影响应用未保存状态；应用拒绝正常退出时停止，不强杀。

更多参数见 API.md。权限或目标不满足时先解决具体原因，禁止用无条件重试掩盖失败。
