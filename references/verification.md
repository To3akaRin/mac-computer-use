# 验证与证据

## 什么算完成

| 动作 | 最小证据 | 不能推断的结果 |
| --- | --- | --- |
| AX 写入 | 重新读回指定元素的值 | 已保存、已发送 |
| CDP 输入 | 独立读取指定元素的新值或内容 | 后端已接收 |
| 点击、按键 | 预期应用状态或产物 | 仅事件派发成功不能说明完成 |
| 截图 | 文件可解码且目标、尺寸一致 | 画面有变化不能说明任务成功 |
| 发布、保存 | 远程回读或实际文件内容 | 不能只凭按钮变色判断 |

工具输出的 `status` 说明工具能验证到的程度。`unknown` 需要重新观察；不要自动重复原动作。测试可以将派发结果与随后独立读回组合成完整证据。

## 输出管理

使用用户指定路径；测试默认放 `artifacts/`。截图和窗口快照应配对保存。最终报告写清实际验证的系统、架构、依赖、场景、结果及未验证项。

原始桌面截图默认不进入开源仓库或 Release。公开验收使用合成测试数据，不混入真实窗口、聊天内容或私人路径。技能没有自动回流或用户档案功能。
